Slide 05: Sistem Development

Arsitektur CSS Modular

Website ini menggunakan 10 file CSS terpisah dengan pendekatan modular: setiap file bertanggung jawab atas satu komponen atau area spesifik. Ini memudahkan maintenance dan kolaborasi tim.

📁 assets/css/ (10 File CSS)

🎨variables.cssDesign tokens & CSS custom properties (warna, spacing, font)2.2 KB
🌐global.cssCSS reset, base styles, utility classes, scroll-reveal5.6 KB
📌navbar.cssNavigasi desktop & mobile, hamburger, promo banner22.7 KB
📋mega-menu.cssDropdown mega menu card layout & animasi8.5 KB
📄pages.cssShared page-level styles (hero, section headers)34 KB
⚙️main.cssLegacy/main styles: hero, services, pricing, footer70.9 KB
👤about.cssHalaman About & Team spesifik (story, timeline)32.9 KB
📝blog.cssBlog listing & article detail page styles5.8 KB
🧩components.cssReusable UI components (cards, badges, buttons)21 KB
🦶footer.cssFooter layout, links, social icons3 KB

🔧 Mengapa Modular?

🧱

Separation of Concerns

Setiap file punya tanggung jawab spesifik: tidak ada "god file" yang mengatur segalanya.

👥

Kolaborasi Tim

Anggota tim bisa bekerja di file berbeda tanpa konflik merge.

🔍

Debugging Mudah

Bug styling? Langsung tahu file mana yang perlu diperbaiki.

📐

CSS Variables (Design Tokens)

variables.css menyimpan semua warna, spacing, dan font: ubah 1 tempat, berubah di seluruh website.

Intersection Observer API

Typing Animation Engine

Hero headline dengan efek ketik otomatis multi-baris.

🖱️

Custom Cursor Tracking

Dual-ring cursor yang mengikuti posisi mouse user.

🔢

Counter Animation

Angka statistik yang menghitung naik secara animatif.

☰

Mobile Menu System

Hamburger toggle, sub-menu accordion, back navigation.

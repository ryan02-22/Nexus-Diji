# Nexus Diji - Solusi Digital Terpercaya

Website portfolio profesional untuk Nexus Diji dengan design modern dan responsif.

## 🚀 Fitur

- ✨ Design futuristik dengan gradient colors (purple, cyan, pink)
- 🎨 Custom cursor animation
- 📱 Fully responsive design
- ⚡ Smooth scroll animations
- 🎯 Service showcase dengan 3 layanan utama
- 📊 Process workflow visualization
- 🔗 Network connection design elements

## 📁 Struktur Project

```
ND/
├── index.html          # Main HTML file
├── assets/
│   └── images/
│       └── logo%20okeh.png    # Nexus Diji Logo
├── .gitignore         # Git ignore file
└── README.md          # File ini
```

## 🎨 Design

- **Color Palette**: Dark theme dengan accent cyan (#00e5ff), purple (#7c3aed), pink (#ec4899)
- **Typography**: Syne (headings), DM Sans (body)
- **Fonts**: Google Fonts CDN

## 💻 Tech Stack

- HTML5
- CSS3 (Custom Properties, Animations, Gradients)
- Vanilla JavaScript (Intersection Observer API)

## 📝 Sections

1. **Navigation** - Fixed navbar dengan logo dan links
2. **Hero** - Landing section dengan headline dan CTA
3. **Services** - 3 layanan utama (Website, Aplikasi, PC Service)
4. **Why Us** - Unique selling points dengan floating cards
5. **Process** - 4 langkah workflow
6. **CTA** - Call-to-action section
7. **Footer** - Links dan copyright

## 🚀 Cara Menjalankan

### Local Server (Python)
```bash
cd c:\All_Project_Kuliah\ND
python -m http.server 8000
```
Buka `http://localhost:8000` di browser.

### Direct Open
Double-click `index.html` atau klik kanan → Open with Browser.

## 📱 Responsive Breakpoints

- Desktop: >= 900px (multi-column layout)
